# Orso Bruno Addon

The Orso Bruno Addon is an open-source project that transforms the polar bear model into a brown bear model for Minecraft Bedrock Edition. This addon includes a custom geometry model for the brown bear, allowing players to spawn and interact with brown bears in their worlds. The project is designed to be easy to install and use, making it accessible to both beginners and experienced players.

## Install

1. Download the addon files from the GitHub repository.
2. Place the addon folder in the `development_behavior_packs` or `development_resource_packs` folder in your Minecraft Bedrock Edition game directory.
3. Launch Minecraft Bedrock Edition and create a new world or edit an existing one.
4. In the world settings, enable the Orso Bruno Addon in the Behavior Packs and Resource Packs sections.

## Use

1. Once the addon is installed and enabled, spawn a brown bear in your world using commands or spawn eggs.
2. Interact with the brown bear as you would with any other mob in Minecraft.
